# Active Sprint

Sprint 074 — Home Feed Extraction Diagnostics is **active**.

The goal of Sprint 074 is to make every profile home-feed collection run explain its result safely before changing extractor behavior.

This sprint should add safe diagnostics and aggregated warning/count summaries so an operator can understand why a run produced zero or few content candidates without exposing raw Facebook payloads or other sensitive runtime data.

This sprint must not change Facebook extraction behavior, browser capture behavior, database schemas, HTTP contracts, profile checkout/leasing, or Content Builder functionality unless the Sprint 074 handoff explicitly narrows and approves such a change.
